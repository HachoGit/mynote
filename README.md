# 理論マイノート

税理士試験の理論暗記のための「赤シート」ノートアプリです。スタディングのマイノート（暗記ツール）に近い見た目と操作を、自分の端末だけで使えるように作りました。Android スマホでの学習と、PC での編集を想定しています。

- ホーム画面に追加してアプリのように使える（PWA）
- オフラインでも使える
- PC とスマホのノートを、合言葉で暗号化して自動同期できる

> **個人利用のためのアプリです。** ノートの中身（予備校の教材など）は各端末の中にだけ保存され、このリポジトリには含まれません。

## 主な機能

**暗記ツール**
- スイッチを ON にすると、赤マーカーの部分が赤く塗りつぶされて隠れる
- 赤い部分をタップすると、そのまとまりが開く（もう一度タップで隠れる）
- 「次を開く」「戻す」で、上から順に1つずつ開け閉めできる
- OFF のときと開いた部分は、文字を細い赤枠で囲んで表示する

**暗記の記録**
- 「✓ 暗記した」で1回記録。タイトルの下と一覧に、回数ぶんの緑のマス（10マスで1段）を表示する
- 押した直後は「取り消す」で戻せる。あとからは、マスをタップした記録の一覧から1件ずつ削除できる
- 記録は PC とスマホで同期され、両方で付けた回数は足し合わされる

**編集**
- 文字を選んで「赤」（PC は Ctrl+B / ⌘+B）を押すと赤マーカーになる
  - 選んだ文字に赤でないものが1文字でもあれば全部を赤に、全部が赤なら解除
- 「見出し」「項目」「本文」で行の種類を変えられる。見出しから目次を自動で作る
- 元に戻す・やり直す（Ctrl+Z / Ctrl+Y）

**スタディングからの貼り付け**
- マイノートの画面をコピーして貼り付けると、赤い部分・太字・見出しをそのまま取り込む
- 画面のメニュー（「100%」「暗記ツール」など）や目次は取り込まない
- うまく取り込めないときは「同期・保存」→「貼り付け診断」の内容で原因を調べられる

**ノートの管理**
- 科目ごとのフォルダ分け、検索
- 本文の上で右にスワイプすると一覧が開く（左スワイプか Android の「戻る」で閉じる）
- 削除は「整理」を押したときだけできる。削除したノートはゴミ箱から戻せる
- 同じフォルダの中では、同じタイトルのノートは作れない。フォルダ名も重複不可

**表示**
- 画面下の「− 100% ＋」で文字の大きさを変えられる
- ヘッダー・タイトル・暗記ツールのスイッチは、スクロールしても上に残る

## インストール（GitHub Pages）

1. このリポジトリを public のまま、Settings → Pages で Branch を `main`、フォルダを `/ (root)` にして Save
2. 1〜2分後に `https://ユーザー名.github.io/リポジトリ名/` で開ける
3. Android の Chrome でそのアドレスを開き、︙ →「ホーム画面に追加」（または「アプリをインストール」）
4. 最初の1回だけ、ネットにつながった状態で開く（以後はオフラインでも使える）

> 無料プランの GitHub Pages は public リポジトリでしか使えません。公開されるのはアプリの仕組みだけで、ノートの中身は公開されません。

## PC とスマホの同期（任意）

ノートを合言葉で暗号化し、自分の GitHub アカウントの非公開メモ（Gist）を経由して同期します。

1. アプリの「同期・保存」→「トークンを作るページを開く」
2. GitHub で Expiration を「No expiration」にし、`gist` だけにチェックが入った状態で「Generate token」→ `ghp_` で始まる文字をコピー
3. アプリにトークンと合言葉（8文字以上、確認用にもう一度）を入れて「接続する」
4. もう一方の端末でも、同じトークンと**同じ合言葉**で接続する

- 編集すると数秒後に自動でアップロード、アプリを開いたときや戻ったときに取り込む
- 同じノートを両方で編集した場合は、更新日時が新しい方が残る（ノート単位）
- 「同期・保存」の前の丸：緑＝同期済み、黄＝同期中、灰＝オフライン、赤＝エラー
- **合言葉は取り戻せません。** 忘れると同期データは読めなくなります（各端末のノートは残ります）
- トークンが漏れた場合は GitHub の Settings → Developer settings → Personal access tokens で削除し、作り直してください。データは暗号化されているので、トークンだけでは中身は読めません

## データの扱い

| データ | 保存場所 |
|---|---|
| ノート・フォルダ | 各端末のブラウザ内（IndexedDB） |
| 同期の暗号鍵 | 各端末のブラウザ内（取り出せない形） |
| 合言葉 | どこにも保存しない |
| 同期データ | 自分の GitHub の非公開 Gist（暗号文のみ） |

- 暗号化：PBKDF2（SHA-256、31万回）で合言葉から鍵を作り、AES-256-GCM で暗号化（gzip 圧縮後）
- 手動のバックアップは「同期・保存」→「テキストでコピー・貼り付け」

## アプリの更新

1. 新しい `index.html`（と `sw.js`）を、このリポジトリに上書きアップロードする（Add file → Upload files → Commit changes）
2. スマホでネットにつながった状態でアプリを開き、一度閉じてもう一度開く

更新してもノートは消えません。ただし、リポジトリ名（＝アドレス）を変えると、新しいアドレスでは空の状態から始まります。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JavaScript をすべて含む） |
| `sw.js` | オフライン用の Service Worker |
| `manifest.webmanifest` | ホーム画面に追加するための設定 |
| `icon-*.png`, `apple-touch-icon.png` | アイコン |
| `tests/run_tests.py` | 動作テスト（Playwright） |
| `CLAUDE.md` | 開発の引き継ぎメモ（Claude Code 用） |

## テスト

```
pip install playwright
python -m playwright install chromium
python tests/run_tests.py
```

GitHub は模擬サーバーで置き換えるため、本物の GitHub にはアクセスしません。
